Return ONLY a JSON object with these keys:
  vascular_invasion        : "present" | "absent" | "unknown"
  vascular_invasion_extent : "focal" | "extensive" | "widely_invasive" | "minimal" | null
  vessel_count             : integer or null  (n vessels involved if explicitly stated)

RULES:

VASCULAR INVASION — count + extent:
  - "focal vascular invasion" → present + extent="focal" + vessel_count=null (unless N stated)
  - "extensive vascular invasion" → present + extent="extensive"
  - "widely invasive follicular carcinoma" → present + extent="widely_invasive"

PERINEURAL INVASION:
