Return ONLY a JSON object with these keys:

RULES:

TRACHEAL INVASION — distinguish three states:
  - "invades the trachea" / "tracheal wall invasion" / "through the tracheal cartilage" → present
  - "tumor SHAVED off the trachea" / "tumor adherent to trachea, shave excision performed" → "shaved"
    (important: shaved = gross adherence requiring shave, but no full-thickness invasion; this is
     often classified as T3b/T4a grey zone — preserve the distinction)
  - "trachea free of tumor" / "no tracheal invasion" → absent
  - Not mentioned → unknown

TRACHEAL INVASION DEPTH (only when present or shaved):
  - mucosal: through the mucosa into the lumen
  - cartilage: into the tracheal cartilage but not through
  - adventitia: tumor into outer adventitia / perichondrium only
  - serosa: same as adventitia
  - full_thickness: through the wall
  - null if depth not stated

LARYNGEAL / CRICOID:
  - "invades the cricoid cartilage" → cricoid_invasion=present AND laryngeal_invasion=present
  - "larynx free of tumor" → laryngeal_invasion=absent
  - Not mentioned → unknown

RECURRENT LARYNGEAL NERVE (RLN):
  - "RLN invaded" / "tumor encasing the RLN" / "sacrificed the RLN" → rln_invasion=present
  - "RLN preserved" / "RLN dissected free of tumor" → rln_invasion=absent
  - "preop vocal cord paralysis" → rln_paralysis_preop=present (STRONG correlate of RLN invasion but different field)
  - "normal preop vocal cord function" → rln_paralysis_preop=absent
  - Not mentioned → both fields = unknown

ESOPHAGEAL INVASION:
  - Same logic as tracheal: present / shaved / absent / unknown

T4A_IMPLICATION:
  - "pT4a" if ANY of these is present: tracheal_invasion=present, laryngeal_invasion=present,
    cricoid_invasion=present, esophageal_invasion=present, rln_invasion=present.
  - "not_pT4a" if all five are absent.
  - "unable_to_determine" otherwise.

Shave-only invasion does NOT automatically confer pT4a — capture it separately and let downstream SQL decide T3b vs T4a based on institutional convention.
