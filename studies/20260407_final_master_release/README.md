# Final master release — study folder template

Replace `20260407` with your release date everywhere below.

## Inputs

1. **Reviewed manual queue** — Complete `verification_status` (and optional reviewer columns) in `manual_review_queue.csv` inside your gate output directory, or copy the reviewed CSV into a new folder and point `--hydrate-mrq-from` there.
2. **Optional** `promotion_review_decisions.csv` — Append-only audit rows for `qa.promotion_review_decisions` (columns aligned with `scripts/sql/114_qa_schema_ddl.sql` plus `decision_batch_id` / `source_object_id` / `evidence_ref` when known).
3. **Optional** final institutional lab CSV — See `scripts/127_analyst_institutional_lab_append.py` docstring for required headers.

## Run

```bash
.venv/bin/python scripts/126_final_master_release.py --md --release-date 20260407 \
  --hydrate-mrq-from studies/v2_domain_promotion_gate_<your_run> \
  --decisions-csv studies/20260407_final_master_release/promotion_review_decisions.csv \
  --lab-csv exports/incoming/final_lab_20260407.csv \
  --ingestion-wave final_institutional_20260407
```

Omit `--lab-csv` / `--ingestion-wave` if no new lab file. Use `--dry-run` to print the plan only.
