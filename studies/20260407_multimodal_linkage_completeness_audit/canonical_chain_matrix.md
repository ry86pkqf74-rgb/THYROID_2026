## Conclusion from matrix

- **Promoted `main` chain** = **separate tables** + **v3 linkages** + optional **specimen** layer — **not** a single shipped **`main.canonical_nodule_chain_v1`** in the contract doc.
- **Full nodule-level deterministic SQL** exists in **`utils/canonical_nodule_linkage.py`** but is **study / optional VIEW** materialization, not the same as **128**’s `mm_contract_dev` star schema.
