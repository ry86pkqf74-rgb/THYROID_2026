## Fit axes for this manuscript (factual)

- **Study design:** Retrospective cohort; **single** integrated database.
- **Primary scientific angle:** **Associations** of cytology / imaging-derived size / limited molecular testing with **initial extent**.
- **Statistical depth:** Multivariable logistic + descriptive concordance; **not** a prognostic model competition.
- **Figures:** **No** figure binaries in folder as of this package — journals requiring mandatory visual flow may need a figure built before submission.
