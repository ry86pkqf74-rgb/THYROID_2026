# M036 distant-metastasis rule — 86 vs 114 M1 gap audit (Cowork, 2026-05-05)

## Context

The M036 v3 ATA 2025 RSS classification fires `high:distant_metastasis` for **86 patients**. The CPM has **114 patients with `ajcc8_m_stage='M1'`** post-mig_313. This is a 28-patient gap that the M036 manuscript prose needs to explain in a footnote or eMethods note.

## Resolution

The gap is fully explained by **non-DTC histologies dropping into the `uncalculable:non_dtc_histology` rule**. The ATA 2025 risk classifier is defined for differentiated thyroid cancer (DTC) only; medullary, anaplastic, poorly-differentiated, and metastatic-other variants are routed to `uncalculable` regardless of M-stage.

## Footnote-quality explanation for M036 manuscript

> "The ATA 2025 RSS classifier is defined for differentiated thyroid cancer only. Of 114 M1-stage patients in the malignant cohort, 86 (75.4%) were classified `high:distant_metastasis`; the remaining 28 had non-DTC histologies (MTC n=10, poorly differentiated n=9, anaplastic n=4, metastatic-other n=5) and were routed to `uncalculable:non_dtc_histology`. M1-stage rate in the strict-DTC subset was 86/3,560 (2.4%), consistent with published Emory metastatic-presentation rates."

## Edge case: 1 FTUMP with M1 stage classified as high:distant_metastasis

One patient with histology `FTUMP` (follicular tumor of uncertain malignant potential — by definition, indeterminate) has `ajcc8_m_stage='M1'` in CPM and is classified `high:distant_metastasis`. This is biologically incoherent — FTUMP is a non-staged borderline category. Two non-mutually-exclusive interpretations:

1. The FTUMP patient has true distant metastasis on imaging (in which case the histology classification needs review — true DM almost certainly indicates a missed malignancy).
2. The M1 flag is a residual data artifact even post-mig_313 (in which case the M-stage derivation has a corner case for non-staged histologies).

## Probe SQL used

```sql
SELECT
  COALESCE(c.histology_final, 'NO_CPM_MATCH') AS histology,
  COUNT(*) AS n,
  SUM(CASE WHEN m.ata_2025_rule_triggered='high:distant_metastasis' THEN 1 ELSE 0 END) AS n_classified_dm,
  SUM(CASE WHEN m.ata_2025_rule_triggered IS DISTINCT FROM 'high:distant_metastasis' THEN 1 ELSE 0 END) AS n_classified_other
FROM main.canonical_patient_master c
LEFT JOIN manuscript_workspace.m036_ata_2025_rss_v2 m
  ON c.research_id = m.research_id
WHERE c.is_malignant AND c.ajcc8_m_stage='M1'
GROUP BY 1
ORDER BY 2 DESC;
```

## Verdict

**Audit clean.** The 86-vs-114 gap is a feature of the ATA 2025 classifier's DTC scope, not a defect. The manuscript footnote is straightforward. The single FTUMP-with-M1 edge case warrants a chart review but doesn't block writing.
