## Findings worth flagging in the manuscript

1. **Non-monotonic ROM in TR1–TR3**: TR1 28.2% → TR2 32.1% → TR3 27.6%. ROM does not strictly increase across the low end; the gradient only kicks in at TR4 (47.4%) and TR5 (58.7%). This is *the* operative-cohort bias signature and should be highlighted explicitly in the Results, not just the Limitations.

2. **Modest discrimination**: AUC 0.648, primary-threshold sens 71% spec 56% — TI-RADS in this surgical cohort is a *modest* discriminator. The story is the calibration distortion, not the discrimination.

3. **PPV inversion vs spec gain**: Going TR≥TR4 → TR≥TR5 only nudges PPV from 55.7% → 58.7% (+3 pp) while sacrificing 16 sens points. Diminishing returns of upgrading threshold in this cohort.
