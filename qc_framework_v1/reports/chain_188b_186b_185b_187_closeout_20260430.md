## §4 Reusable patterns (4 new)

1. **Self-join row-count inflation on UPDATE** — `UPDATE ... FROM event_derivation src WHERE tgt.key=src.key` reports M×N matched rows when the target has duplicate-grain rows. Cowork verified §D applied correctly by querying actual distribution rather than trusting the row count.
2. **Bethesda/POC col preservation across chain rebuilds** — when a chain rebuild drops cols (mig_186b §D2 case), source them from the EARLIER pre-rebuild snapshot, not the immediately-preceding pre-snapshot. The PRE-186b rollup snapshot still has the cols mig_185b needs.
3. **Cowork-direct CREATE OR REPLACE VIEW patch as remediation** — when a Python deploy script regresses VIEW SQL (drops a WHERE filter), issue a Cowork-direct CREATE OR REPLACE VIEW with the corrected SQL rather than rolling back + re-running the deploy. Faster + verifiable.
4. **MD MCP wrapper handles long Python script as opaque RPC** — Desktop Commander interactive process timed out at 60s but the Python script kept running and committed. Always verify the actual MD state (VIEW row count, etc.) rather than trusting the Python output.
